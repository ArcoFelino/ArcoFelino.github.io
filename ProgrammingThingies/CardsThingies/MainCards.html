Apex Roleplay commands review!

What is the correct way to format a dataedit command?

_dataedit [category (unit, effect)] [selection (marine, guassrifle)] [value type] [new value]

What is the correct way to alias a command?

alias create [alias name] [command itself]

What is recommended NOT to do when doing a @copy +visual command?

Target multiple units at the same time, game might crash.

How to save the placemant of units in the map?

_gamesetup save [gamesetup name]

How to make something shoot nukes?

Use the dataedit command making a weapon have the nuke effect instead of the default damage effect.

How to copy the stats and modeling of a unit?

Using @copy +visual command. The _dataedit and _replace model commands will make it for every single of that type of unit

How to make things talk?

Using the @say command.

How to color the font of the text?

Video Embedding Tutorial

This tutorial is meant for the people that want to learn step-by-set how to embed a video to their webpage.

Step 1

Find the video you want to embed in your page. In this example we will use a YouTube video, but there are other hosting platforms that may work in a similar way. Once you find the video, find and select the share or embed or similar option.

Step 2

Configure the embedding options. By default, Youtube will simply allow player controls which mean allowing the user to pause, play, fast worward, etc. We could also set a start time of the video or other options, but for now, it is ok as it is. You could also hardcode the options using a similar code than the code YouTube provides you but it is easier to copy and paste without changing anything. After the most general options are set as you'd like them to be, just copy the code, either manually or by clicking the "copy" button

Step 3

Now simply paste the embed code in the place in your page where you want it to be. The iframe tag can be configured as any other tags, although make sure not to mess with things you don't know about. The easiest things to change are the width and tthe height to whichever properties you require. There will be some times the iframe does not work and there are fixes for it over the internet but we will not cover that in this tutorial.
